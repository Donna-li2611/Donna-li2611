## 我的工作方式

1. 先明确一个具体用户问题，再决定是否需要 AI。
2. 通过可体验的原型识别交互问题，再进入更重的工程实现。
3. 将事实、解释和待验证假设分开记录。
4. 用测试、实验条件和失败案例说明结果的适用边界。

我使用 AI 辅助研究、编码与材料整理。项目中的需求取舍、设计约束和验收标准另有记录；代码量不用于代表独立手写工作量。每个仓库区分已实现、已验证与计划中的能力。
